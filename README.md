# The Christmas Tower

*A Story of Migdal Eder, the Tower of the Flock*, by David Haines.

An old stone tower on a hill above Bethlehem tells how it held the lambs, then held the Lamb, and was given a new name. The site is set up for families to read the book aloud together across two evenings.

**Read it:** <https://ireaneus.github.io/ChristmasTower/>

## Building

```sh
npm ci
npm run build   # writes _site/ from content/christmas-tower-v11.md
npm run check   # verifies the site against the manuscript
npm run preview # local preview at http://localhost:8080
```

See `CLAUDE.md` for project conventions and `SITE_BRIEF.md` for the full spec. The original site is preserved at the git tag `original-site`.
